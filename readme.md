README: Простой HTTP‑сервер на Python
Этот скрипт реализует минимальный HTTP‑сервер на базе встроенного модуля http.server. Он:

обрабатывает GET‑запросы (отдаёт HTML, CSS, JS, изображения);

принимает POST‑запросы из форм;

выводит данные формы в консоль;

делает редирект на главную страницу после отправки формы.


## Установка:

1 Клонируйте репозиторий:
``` git clone git@github.com:lidiar8r-ops/coursework_3.git  ```

2 Перейдите в папку проекта:
``` cd ваш_репозиторий```

3 Установите зависимости:
``` pip install -r requirements.txt```

Структура проекта
```
project_folder/
├── main.py                # Этот скрипт
├── html/
│   └── contacts.html       # Контакты 
│   └── category.html       # Категория 1
│   └── catalog.html        # Каталог 
│   └── index.html          # Главная страница 
├── css/
│   └── *.css               # Стили Bootstrap
│   └── styles.css          # Стили
├── js/
│   └── *.js                # Скрипты  Bootstrap
└── img/
    └── logo.png            # Изображения
```    
Как запустить
Разместите файлы согласно структуре выше.

Откройте терминал в папке со скриптом.

Выполните:

bash
python main.py
Откройте в браузере:
→ http://localhost:8080

Настройка
Порт сервера
Измените serverPort в коде:

python
serverPort = 8080  # Например, 5000 или 3000
Хост
Чтобы сервер был доступен извне, замените:

python
hostName = "0.0.0.0"  # Вместо "localhost"
Путь к файлам
Если структура папок отличается, скорректируйте CURRENT_DIR и пути в do_GET.


После отправки формы:

Данные выводятся в консоль сервера.

Пользователь перенаправляется на http://localhost:8080/.

Логирование в консоли
При работе сервера вы увидите:

[GET] Запрос: /css/styles.css — запросы на файлы.

[POST] Получен запрос: /submit — отправка формы.

Блок ПОЛУЧЕНЫ ДАННЫЕ ФОРМЫ с полями формы.

Сервер запущен: http://localhost:8080 — старт сервера.

Сервер остановлен. — завершение работы (по Ctrl+C).

Остановка сервера
Нажмите Ctrl+C в терминале, где запущен скрипт.

Ограничения
Нет валидации данных — для продакшена добавьте проверку полей.

Не подходит для высокой нагрузки — используйте Flask/Django для сложных проектов.

Безопасность — не рекомендуется для публичных сервисов без HTTPS и аутентификации.
